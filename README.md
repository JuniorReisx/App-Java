# 💱 **App de Cotação do Dólar**

## Descrição

Este é um aplicativo que permite ao usuário consultar a cotação do dólar e realizar operações de adição e subtração com o valor em dólar, mas somente após realizar o login. O app foi desenvolvido com o objetivo de fornecer uma forma simples e rápida de realizar conversões e cálculos envolvendo a moeda americana.

### Funcionalidades:
- 🔒 **Login Requerido**: O usuário precisa fazer login para acessar as funcionalidades do aplicativo.
- 📈 **Cotação do Dólar**: Exibe a cotação do dólar (definida manualmente no app).
- ➕ **Operações de Adição e Subtração**: Permite adicionar e subtrair valores em dólar.
- 🧑‍💻 **Interface Simples e Intuitiva**: Foco na usabilidade para uma experiência rápida e eficiente.
